# 常见问题排查

> **遇到问题先做这一件事**：在项目目录下执行 `python check_env.py`。
> 它会逐项检查并直接告诉你哪里不对。下面按"界面上的报错文字"来查。

---

## 一、启动阶段

### 双击 `start.bat` 窗口一闪就没了

说明启动过程中报错了。解决办法：打开命令行手动运行，就能看到错误。

```
cd /d 你的项目路径
python check_env.py
python main.py
```

### `No Python at '...'` / `python 不是内部或外部命令`

电脑上没装 Python，或者装的时候没勾选 "Add Python to PATH"。

**解决**：去 https://www.python.org/downloads/ 装一个 3.10 以上的版本，
安装界面的**第一屏底部有个 "Add Python to PATH" 的勾选框，一定要勾上**。

### `ModuleNotFoundError: No module named 'gradio'`（或 pydub / edge_tts / openai …）

依赖没装齐。

**解决**：
```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### `ModuleNotFoundError: No module named 'audioop'`

Python 3.13 删除了这个内置模块，需要补丁包。

**解决**：
```
pip install audioop-lts
```
（其实装 gradio 时会自动带上；如果报这个错，说明装的时候漏了）

### 浏览器没自动打开

不是故障。手动打开浏览器，地址栏输入：`http://127.0.0.1:7860`

### `端口 7860 已被占用`

上一次的程序没关干净。

**解决**：关掉所有黑色的命令行窗口，重新双击 `start.bat`。
仍然不行就执行：
```
netstat -ano | findstr :7860
taskkill /F /PID 上面查到的数字
```

## 二、抓取网页阶段

### 「抓取失败：HTTP 403」

对方网站拒绝程序访问。常见于需要登录、或者明确禁止爬取的网站。

**解决**：换个网站；或者手动把内容复制粘贴到"文章内容"框里。

### 「抓取失败：HTTP 404」

网址写错了，或者页面已经被删除。检查一下链接。

### 「抓到的内容太少了（可能这个网页是用 JavaScript 动态加载的）」

有些网页的文字不是直接写在 HTML 里，而是打开后用脚本加载的，
普通抓取方式看不到。

**解决**：手动复制正文内容粘贴进去。

### 抓回来的中文是乱码

极少见。一般是目标网站编码声明有误。**解决**：手动复制粘贴。

## 三、文案生成阶段

### 输出开头写着「【演示模式】未检测到可用的 AI 接口密钥」

`.env` 里的密钥没填、填错了，或者文件没建。

**解决**：确认项目目录下有 `.env` 文件（不是 `.env.txt`），
里面的 `OPENAI_API_KEY=` 后面确实填了 `sk-` 开头的密钥。

> 小技巧：记事本保存时容易存成 `.env.txt`。打开"文件资源管理器 → 查看 →
> 勾选「文件扩展名」"，就能看到真实文件名了。

### 「AI 接口调用失败：账户余额不足」

DeepSeek 账户没钱了，去官网充值。

### 「AI 接口调用失败：密钥无效」

密钥过期或被删除了。去 DeepSeek 后台重新创建一个，更新到 `.env` 里。

**不需要重启程序**——改了 `.env` 立即生效。

### 生成的字数总是不对

大模型对字数的控制本来就做不到百分之百精确。系统会自动校正一次，
但仍有偏差。**解决**：在文案框里手动增删几句。

## 四、配音阶段

### 「第 1 句合成失败：Invalid rate '0%'」

这是**旧版本**的 bug，新版本已经修好了。如果你看到这个报错，
说明你在用改造前的代码。

### 「微软语音合成失败」/ 用的是在线音色但没声音

微软语音需要联网。

**解决**：检查网络；或者改用"语音克隆"（本地运行，完全不需要网络）。

### 「语音服务未启动。请先点「🚀 启动服务」」

按提示点一下那个按钮，等状态栏变成"✅ 语音服务已就绪"再合成。

### 点「启动服务」后一直显示"正在等待模型加载…"

首次启动要 10-30 秒。如果超过 1 分钟还没好，看那个弹出的黑色窗口里的报错。

**常见原因**：
- 显存不足 → 关掉游戏、浏览器里的视频、其他占用显卡的程序
- 模型文件损坏 → 重新运行 `copy_sovits.bat` 搬运

### 「服务进程启动后立刻退出了」

多半是显存不够。**解决**：关掉其他占显卡的程序再试。

用这个命令可以看当前谁在占显卡：
```
nvidia-smi
```

### 「连不上语音服务」

服务没起来，或者被防火墙拦了。

**解决**：先执行 `stop_gpt_sovits.bat` 再点「🚀 启动服务」。
还不行就用 `start_gpt_sovits.bat` 单独启动，看它报什么错。

### 「端口 9880 仍被占用」

上一次的语音服务没关干净。

**解决**：双击 `stop_gpt_sovits.bat`。

### 合成的音频有明显的电流声/杂音

一般是参考音频质量差。

**解决**：换一段干净的人声（5~10 秒，无背景音乐、无环境噪音）。

### 上传自己的参考音频后，声音不像我

两个要求：
1. **参考音频 5~10 秒**，太短学不到音色，太长反而会飘
2. **「参考音频对应的文本」必须和音频里说的话一字不差**

第 2 条最容易出错——填错了会导致语气和韵律明显跑偏。

## 五、音频文件相关

### 「音频合并导出失败」

多半是磁盘空间不足或路径被占用。

**解决**：检查 F 盘剩余空间；确认没有播放器正打开着生成的 mp3。

### 生成的 mp3 怎么这么大？

人声用 96k 码率足够清晰。想改的话，在 `.env` 里加一行：

```
MP3_BITRATE=64k
```

## 六、还是解决不了

1. 打开 `outputs/logs/app.log`，拉到最下面，那里记录了完整的错误过程
2. 执行 `python check_env.py`，把结果截图
3. 把上面两样一起提供，就能定位问题了
