## 一、项目概况

**项目名称**：多源文本融合与语音克隆配音系统

**一句话说明**：输入若干网页链接，系统自动抓取正文、融合多篇文章的内容，
用大语言模型生成一段适合口播的视频文案，再用语音克隆技术配上人声，
最终输出一个可直接用于短视频的音频文件。

**技术路线**：

```
网页抓取          多源融合          文案生成           语音合成
requests          拼接多篇文章       DeepSeek          ├─ 微软在线 TTS
+ BeautifulSoup   + 去重结构化       大语言模型         └─ GPT-SoVITS 语音克隆
(HTML 解析)                                              (本地部署 + 自训练模型)
```

## 二、核心功能与对应实现

| 功能 | 实现方式 | 所在文件 |
|---|---|---|
| 网页正文抓取 | requests 请求 + BeautifulSoup 解析，剔除脚本/样式/导航等非正文标签 | `article_extractor.py` |
| 多源文本融合 | 多篇文章按分隔标记合并后统一送入大模型，由其提炼整合 | `main.py` / `script_generator.py` |
| 文案生成 | 调用 DeepSeek 大模型，按风格/字数/创意度参数化生成，并自动校正字数 | `script_generator.py` |
| 文案润色 | 按用户给出的修改建议二次调用大模型改写 | `script_generator.py` |
| 语音合成（在线） | edge-tts 调用微软语音服务，10 个中文音色 | `speech_synthesizer.py` |
| **语音克隆（本地）** | GPT-SoVITS v2Pro，加载**自行训练的 7Nanometer 模型**，本机 GPU 推理，全程离线 | `speech_synthesizer.py` |
| 长文本处理 | 按标点智能切句 → 逐句合成 → 插入停顿 → 拼接 → 统一响度 → 导出 | `speech_synthesizer.py` |
| 图形界面 | Gradio 网页界面，双标签页 | `main.py` |

## 三、关键技术难点

### 1. 语音克隆模型的训练

- **素材**：一段约 20 分钟的解说音频（《阿基拉》漫画解说）
- **处理**：切分为 126 个片段，自动语音识别生成对应文本
- **训练**：GPT-SoVITS v2Pro 框架，SoVITS（声学模型）+ GPT（语气模型）双路微调
- **环境**：RTX 4060 Laptop（8GB 显存），LoRA 微调，批次 4，共 8 轮
- **产物**：`7Nanometer_e8_s272.pth`（声学）+ `7Nanometer-e15.ckpt`（语气）

### 2. 超长文本的语音合成

大模型输出的文案常达数千字，一次性送入语音引擎会导致显存溢出或超时。
方案是**三级切分**：

```
按句末标点切句  →  超长句按字数硬切  →  句子攒成不超过阈值的块
```

逐块合成后再拼接，并在句间插入停顿（网页界面可调 200~1500 毫秒），
最后统一拉平各句响度，避免"忽大忽小"。

### 3. 网页正文提取的鲁棒性

网页结构千差万别，需要处理：

- **编码识别**：中文网站编码有 UTF-8、GBK 等多种，仅在服务器未声明时才自动探测
- **正文定位**：优先提取 `<article>` / `<main>` 语义标签，取不到再回退整页
- **噪声剔除**：移除脚本、样式、导航栏、页脚、侧边栏等非正文区域
- **错误区分**：403/404 等错误响应与"抓到空内容"分别报错，不会污染后续流程

## 四、验收步骤

### 环境自检

```bash
python check_env.py
```

预期输出：全部显示"通过"，末尾提示"一切正常"。

### 功能验收

| 序号 | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| 1 | 网页抓取 | 输入 2 个网址，点"从网址提取文章" | 文章框出现正文；若有失败网址，状态栏单独提示 |
| 2 | 文案生成 | 点"生成文案" | 输出符合字数要求、无 `【】` 标记的口播文案 |
| 3 | 在线配音 | 声音选"云希"，**保持语速/音量为默认的 0**，点"合成配音" | 成功生成音频，可播放 |
| 4 | 语音克隆 | 点"启动服务"等待就绪 → 勾选"使用语音克隆" → 合成 | 用训练的声音朗读，与在线音色明显不同 |
| 5 | 模型对比 | 播放 `outputs/audio/` 下的两个对比文件 | `对比_2_我训练的模型.mp3` 音色更接近训练素材 |

### 环境与性能

- 显卡：NVIDIA GeForce RTX 4060 Laptop（8GB 显存）
- 语音克隆推理速度：约 13 秒语音耗时 15 秒（含模型预热）
- 语音服务探活：平均 2 毫秒/次，不占用 GPU
