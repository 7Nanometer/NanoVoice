# 换机器部署

> 把系统搬到另一台电脑上运行（比如答辩用的机器、或者交给老师）。

---

## 一、目标机器需要什么

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11 64位 | |
| Python | 3.10 或更高 | 去 https://www.python.org/downloads/ 下载，**安装时务必勾选 "Add Python to PATH"** |
| 显卡 | NVIDIA，显存 ≥6GB | 只有用"语音克隆"才需要；只用微软在线音色不需要 |
| 显卡驱动 | 已安装 | 命令行执行 `nvidia-smi` 能看到显卡信息就说明装好了 |
| 磁盘空间 | ≥20GB | 语音引擎占约 16GB |
| 网络 | 能上网 | 抓网页、生成文案、微软音色需要；纯本地克隆不需要 |

## 二、拷贝什么

把**整个 `GradProject` 文件夹**拷过去就行。它已经是自包含的了。

```
GradProject/            ← 整个文件夹复制到目标机器（U盘 / 移动硬盘 / 网盘）
├─ 源代码 7 个 .py
├─ GPT-SoVITS/          16GB，含语音引擎和你训练的模型
├─ outputs/             可以不拷（是运行产物）
├─ docs/ assets/        建议一起拷
├─ requirements.txt     依赖清单
└─ .env                 ★ 不要拷！密钥不能跟着走，到目标机器上重新填
```

> **为什么 `.env` 不要拷？**
> 那里面是你的 API 密钥，等于账号密码。拷过去万一被别看到，别人就能用你的额度和钱。

**预计大小**：约 17GB。
如果用 U 盘拷贝，注意 U 盘格式要是 exFAT 或 NTFS（FAT32 单个文件不能超过 4GB，
而语音引擎里有大文件，会拷失败）。

## 三、目标机器上的操作

### 1. 装 Python

下载安装 Python 3.10+，**记得勾选 "Add Python to PATH"**。

装完后打开命令行（Win+R 输入 cmd），执行 `python --version`，
能看到版本号就说明装好了。

### 2. 装依赖

```
cd /d 你放 GradProject 的路径
pip install -r requirements.txt
```

慢的话加镜像：
```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 填密钥

把 `.env.example` 复制成 `.env`，填上自己的 DeepSeek 密钥。

### 4. 自检

```
python check_env.py
```

**必须看到"失败 0 项"**。如果有失败项，按提示处理。

### 5. 启动

双击 `start.bat`。

## 四、路径会自动适配

这个系统做了特殊处理，**不管你放在哪个盘、文件夹叫什么名字，都能直接跑**：

- 所有路径都以"代码文件自己的位置"为基准计算，不写死盘符
- 语音引擎自带 ffmpeg，目标机器**不需要**额外安装 ffmpeg
- 如果语音引擎放在项目外面的其他位置，在 `.env` 里加一行指定即可：

```
GPT_SOVITS_DIR=D:\某个位置\GPT-SoVITS
```

## 五、验收清单

按顺序做一遍，全部通过就算部署成功：

- [ ] `python check_env.py` → 失败 0 项
- [ ] 双击 `start.bat` → 浏览器自动打开界面
- [ ] 文案生成：粘一段文章 → 点生成 → 有文案输出（不是"演示模式"提示）
- [ ] 在线配音：声音选"云希"，语速音量保持 0，点合成 → 有音频能播放
- [ ] 语音克隆：点"启动服务"→ 等就绪 → 勾选使用克隆 → 合成 → 是训练的声音

## 六、常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示 `python 不是内部或外部命令` | 装 Python 时没勾 "Add to PATH" | 重新安装并勾选，或手动把 Python 目录加进系统 PATH |
| `pip install` 卡住不动 | 默认源在国外，网速慢 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 语音服务启动后立刻退出 | 显存不够 | 关掉游戏和其他占显卡的程序；或改用在线音色 |
| 拷贝中断，文件不全 | U 盘是 FAT32，放不下大文件 | 换成 exFAT 或 NTFS 格式 |
| 双击 bat 一闪而过 | 里面报错了 | 在命令行里执行 `python check_env.py` 看具体错误 |
| 中文显示成乱码 | 命令行编码不对 | 本项目已处理；若仍出现，执行 `chcp 65001` 后重试 |
