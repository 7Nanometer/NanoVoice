# 快速开始

> 从头到尾大概 10 分钟（不含下载等待）。

---

## 三步走

### 第 1 步：装依赖（只做一次）

按 `Win + R`，输入 `cmd`，回车，打开黑色命令行窗口。然后输入：

```
F:
cd F:\GradProject
pip install -r requirements.txt
```

> **这些命令在干什么？**
> `F:` 是切换到 F 盘；`cd` 是进入某个文件夹；
> `pip install` 是 Python 的"应用商店"，按清单把需要的零件都装好。
>
> 下载慢的话，在后面加一句国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 第 2 步：填密钥

1. 在项目文件夹里找到 `.env.example`
2. 复制一份，把副本改名为 `.env`（注意：前面有个点，没有后缀名）
3. 用记事本打开它
4. 找到这一行：`OPENAI_API_KEY=在这里填你的密钥`
5. 把 `在这里填你的密钥` 换成你的真实密钥，保存

> **密钥是什么？**
> 就是调用 AI 接口的"会员卡号"。去 https://platform.deepseek.com 注册，
> 在后台创建一个，形如 `sk-` 开头的一长串字符。
>
> 不填也能启动，但生成文案时会走"演示模式"——只是把文章里的句子拼一拼，
> 不是真正的 AI 创作。

### 第 3 步：双击 `start.bat`

会出现一个黑色窗口，先自动做环境自检，然后浏览器会自动打开操作界面。

**关掉那个黑色窗口 = 退出系统。**

---

## 界面怎么用

界面分两个标签页，按顺序来：

### ① 文案生成

**方式 A：从网址抓**

1. 左边「网址列表」里，一行贴一个网址（可以贴多个）
2. 点「🔗 从网址提取文章」
3. 抓到的正文会出现在下面的框里；哪条失败了会在最下面的「抓取状态」里说明

**方式 B：直接粘贴**

把文章内容直接粘进「文章内容」框。

> 要放多篇文章的话，文章之间用一行 `======== 文章分隔 ========` 隔开。
> （从网址抓取时会自动插入这个标记）

**然后：**

- 选风格、拉字数、调创意程度
- 点「✨ 生成文案」
- 文案出来后，可以在框里**直接手动修改**
- 不满意可以写句修改建议，点「✏️ 按建议润色」

### ② 语音合成

**用微软在线音色（简单，不需要显卡）**

1. 「选择声音」里挑一个（云希是男声，晓晓是女声）
2. 语速、音量、停顿按需调（**保持默认就好**）
3. 直接点「🎤 合成配音」

> 注意：微软语音需要联网。

**用你自己的克隆声音（效果更特别，需要显卡）**

1. 找到「🔊 语音克隆」区域，点「🚀 启动服务」
2. 等状态栏显示「✅ 语音服务已就绪」（首次要 10-30 秒，会弹出一个黑色窗口，那是正常的）
3. 声音选「🎙️ 我的克隆声音」，或者勾上「使用语音克隆」
4. 点「🎤 合成配音」

> **不传参考音频也能用**——系统会用它内置的那段训练音频。
> 想克隆自己的声音，就上传一段 3~10 秒的清晰录音，
> 并把录音里说的话一字不差地填到「参考音频对应的文本」里。

## 生成的文件在哪

```
outputs/
├─ audio/     成品配音（文件名带时间戳，不会互相覆盖）
├─ scripts/   生成的文案（写论文时方便引用）
└─ logs/      运行日志（出问题时看这里）
```

---

## 遇到问题

先运行一次环境自检：

```
python check_env.py
```

它会逐项检查并告诉你哪里有问题。更多排查方法见 [03-常见问题排查.md](03-常见问题排查.md)。
