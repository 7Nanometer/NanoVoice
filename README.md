# 多源文本融合与语音克隆配音系统

一个从「网页链接」到「配音成品」的自动化系统。

---

## 这个系统能干什么

给它几个网页链接（或者直接粘贴文章），它会自动：

```
网址列表  →  抓取正文  →  多篇融合  →  生成口播文案  →  切句配音  →  输出 MP3
```

配音有两条路可选：

| 方式 | 特点 | 需要联网 | 需要显卡 |
|---|---|---|---|
| 微软在线语音 | 10 个现成音色（男声女声都有） | 需要 | 不需要 |
| **本地语音克隆** | 用**自己训练的声音**说话 | **不需要** | 需要 |

---

## 三步跑起来

### 第 1 步：装依赖（只做一次）

打开命令行，进入本目录，执行：

```
pip install -r requirements.txt
```

> 下载慢的话加国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 第 2 步：填密钥

把 `.env.example` 复制一份、改名为 `.env`，用记事本打开，
在 `OPENAI_API_KEY=` 后面填上你的 DeepSeek 密钥。

> 密钥去 https://platform.deepseek.com 注册申请。
> 不填也能启动，但只能看到"演示模式"的假文案。

### 第 3 步：双击 `start.bat`

系统会自动做环境自检，然后打开浏览器界面。

要用语音克隆的话，进去后点一下「🚀 启动服务」，等它显示"已就绪"（首次约 10-30 秒）。

## 目录说明

```
├─ main.py                 主程序：网页界面 + 流程调度
├─ article_extractor.py    从网址抓取文章正文
├─ script_generator.py     调用 AI 生成口播文案
├─ speech_synthesizer.py   文字转语音、切句、拼接、导出
├─ config.py               ★ 所有配置集中在这里（改路径/换模型只改这个文件）
├─ logger.py               日志系统
├─ check_env.py            环境自检（跑不通时先运行它）
├─ run_sovits.py           单独启动/停止语音引擎（排查问题用）
│
├─ start.bat               一键启动
├─ start_gpt_sovits.bat    只启动语音引擎（排查用）
├─ stop_gpt_sovits.bat     停止语音引擎
├─ copy_sovits.bat         搬运语音引擎（换机器时用）
│
├─ GPT-SoVITS/             语音引擎（含你训练的声音模型，约 16GB）
├─ outputs/                运行产物：音频、文案、日志
├─ docs/                   详细文档（建议按顺序看）
└─ assets/                 训练素材原件
```

## 使用须知

- 抓取网页时请遵守目标网站的规定（`robots.txt`），不要高频请求。
- 语音克隆功能只能用于你**有权使用**的声音素材，不得用于伪造他人身份。
- `.env` 文件含密钥，不要发给别人、不要上传网盘。
